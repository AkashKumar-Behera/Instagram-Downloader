# Instagram Downloader Tool

This tool allows you to download public Instagram **Posts, Reels, Images, and Carousels**.

---

## 🚀 How to Run the Web GUI App

1. Open terminal and run:
```bash
python c:\Development\insta-downloader\app.py
```
2. Open your browser at: **`http://localhost:5000`**
3. Paste any Instagram URL (e.g. `https://www.instagram.com/p/DUYW53OCe2y/`) and click **Download**.

---

## 💻 How to Use via Command Line (CLI)

Run:
```bash
python c:\Development\insta-downloader\cli.py "https://www.instagram.com/p/DUYW53OCe2y/"
```
All downloaded media files will be saved in the `c:\Development\insta-downloader\downloads` directory!
